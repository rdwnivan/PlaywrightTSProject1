# Context

## Project

Playwright TypeScript Project - Automated testing project using Playwright with TypeScript.

## Domain Terms

| Term | Definition |
|------|------------|
| Page Object | A class that encapsulates page-specific elements and actions |
| Test Data | External data files (CSV, JSON) used to drive test scenarios |
| Fixture | Playwright's mechanism for providing test dependencies |

## Architecture

- **Framework**: Playwright Test
- **Language**: TypeScript
- **Linting**: ESLint with Playwright plugin
- **Test Data**: CSV files parsed with csv-parse
