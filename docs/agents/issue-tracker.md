# Issue Tracker

## Type

Local markdown

## Convention

Issues live as markdown files under `.scratch/<feature>/issues/`.

## File naming

One file per issue: `.scratch/<feature>/issues/<number>-<slug>.md`

## Issue format

Each issue file should contain:

- **Title** — short description
- **Status** — current triage status
- **Description** — what needs to be done
- **Acceptance criteria** — how to know it's done
- **Blocking edges** — what this blocks, or what blocks this
