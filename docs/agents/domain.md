# Domain Docs

## Layout

Single-context: one `CONTEXT.md` at the repo root.

## Consumer rules

- Read `CONTEXT.md` at the start of any session to understand the project's domain language
- Read `docs/adr/` when making architectural decisions
- Update `CONTEXT.md` when new domain terms are introduced
- Create ADRs in `docs/adr/` when making significant architectural decisions
